## 🚀 How to Run Locally

Simply open `index.html` in any web browser, or launch a quick local server:

```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

---

## 🌐 Enabling GitHub Pages

To make the site instantly accessible to Mrigesh from anywhere:
1. Go to repository settings on GitHub: [Settings -> Pages](https://github.com/manandewan/happybirthday/settings/pages)
2. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. The site will be live at `https://manandewan.github.io/happybirthday/`!
